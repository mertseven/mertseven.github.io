# NMED Graduation Showcase

GitHub Pages üzerinde çalışacak bağımlılıksız statik showcase.

## Yayınlama

Depo ayarlarında **Pages → Deploy from a branch** seçin ve `showcase/` klasörünü yayın kökü olarak kullanın. GitHub Pages klasör seçimi yalnızca `/` veya `/docs` sunuyorsa `showcase` içeriğini `/docs` klasörüne taşıyın.

Yerel önizleme için `showcase/index.html` dosyasını doğrudan tarayıcıda açabilirsiniz.
